# Система планирования сборки RPM-пакетов

## Назначение
Программа автоматически строит ациклический план сборки для заданного набора RPM-пакетов на основе анализа их .spec-файлов. Учитывает:
- зависимости BuildRequires;
- пакеты, уже доступные в репозитории (available);
- циклические зависимости (диагностика ошибок);
- режим пересборки зависимых пакетов (--rebuild-dependents).

## Архитектура
- parser.py – извлекает из .spec-файлов Name, Provides, BuildRequires, строит индекс capability -> пакеты.
- resolve.py – разрешает зависимости, выбирает provider’ов, строит final_to_build и граф resolved_deps.
- planner.py – строит ациклический граф стадий (КСС, топологическая сортировка), выявляет циклические компоненты.
- main.py – интегрирует этапы, обрабатывает аргументы, выводит JSON-план или ошибку.

## Запуск
```
python3 main.py <specs_dir> <available.txt> <required.txt> [--rebuild-dependents]
```
- specs_dir – директория с .spec-файлами.
- available.txt – список уже доступных пакетов (по одному на строку).
- required.txt – список пакетов, которые нужно собрать.
- --rebuild-dependents – добавить в план пакеты, зависящие от запрошенных (по умолчанию флаг равен False).

## Результат

При успехе – JSON с полем "plan", содержащим список стадий (stages). Каждая стадия имеет:
- id – порядковый номер;
- packages – пакеты для сборки;
- type – acyclic / cycle (диагностика);
- depends_on – ID стадий, которые должны быть выполнены раньше.

При неразрешимом цикле – JSON с полем "error" и кодом возврата 1.

## Ключевые особенности

- Изоляция – все этапы работают с копиями данных, не изменяют исходные spec-файлы.
- Детерминизм – выбор provider’а и порядок сборки воспроизводимы.
- Объяснимость – в JSON выводится причина каждой стадии

## Требования к окружению
- Python
- Установленные пакеты: specfile, системные библиотеки: python3-rpm

## Тестирование

Тесты проверяют корректность работы всей системы планирования сборки RPM-пакетов. Они разбиты на две группы:
- tests.py – интеграционные тесты на реальных spec-файлах (gcc, binutils, isl, autoconf, automake, libtool). Проверяют базовую функциональность: парсинг, разрешение зависимостей, построение ациклического графа стадий, обработку ситуаций с уже доступными пакетами.
- tests_rebuild_dependent.py – тесты для проверки режима --rebuild-dependents, который добавляет в план сборки пакеты, зависящие от запрошенных.

### Запуск тестов
Для запуска тестов требуется установленный pytest
```
# Из корня проекта
pytest tests/tests.py -v
pytest tests/tests_rebuild_dependent.py -v
```
